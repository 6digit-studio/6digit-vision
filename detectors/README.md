# detectors — the eyes instrumentation catalog

Each subdirectory is one replay of `challenges/EYES_DETECTOR_CHALLENGE.md`:
a standalone detector for a defect class `eyes` cannot yet catch, proven
against the eval case that named the gap, with an honest CAUGHT/PARTIAL/
MISS verdict in VERDICT.md.

Detectors consume `eyes` outputs and live beside the instrument —
integration into `eyes/` is a walk decision, not a contestant one.
